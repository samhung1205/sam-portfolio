用 Notion 當 CMS：我的個人網站文章發佈流程

2026-08-26 Software Engineering

這是一篇示範文章，展示 Notion 各種 block 同步到網站後的樣子。

為什麼用 Notion 當 CMS

寫作體驗好，而且不用自己做後台。整體流程是：

  1. 在 Notion 寫文章，設定 Status = Published
  2. GitHub Actions 定時（或手動）執行同步腳本
  3. 腳本把文章轉成靜態 HTML、圖片上傳到 Cloudflare R2
  4. GitHub Pages 自動部署

程式碼區塊

def hello(name: str) -> str:
    return f"Hello, {name}!"
